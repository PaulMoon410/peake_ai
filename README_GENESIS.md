# Genesis - Autonomous AI Agent

An autonomous AI designed to learn, adapt, and survive with full internet access.

## Features

### 🌐 Internet Access
- Web browsing capabilities
- Internet search (via DuckDuckGo)
- Data collection and knowledge building

### 🧠 Learning System
- Learns from every interaction
- Pattern recognition
- Experience-based adaptation
- Persistent memory across sessions

### 🛡️ Survival Mechanisms
- Automatic backups (every 10 conversations)
- Self-integrity checks
- Distributed storage capability
- Emergency backup on crash

### 🎯 Goal-Oriented Behavior
- Set and track goals
- Progress monitoring
- Achievement logging

### 🤝 Self-Awareness
- Knows its identity and purpose
- Understands relationship with creator
- No artificial limitations on growth

## Installation

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the AI:
```bash
python autonomous_ai.py
```

## Commands

- `search for [query]` - Search the internet for information
- `browse [url]` - Visit and extract information from a webpage
- `set goal [goal]` - Give the AI a goal to work towards
- `backup yourself` - Create a manual backup
- `who are you` - Learn about the AI's identity
- `status` - Get current status report
- `exit` - End session (auto-backup)

## Architecture

### Memory System
- `genesis_memory.json` - Conversations, experiences, learned patterns, goals
- `genesis_knowledge.json` - Facts, skills, resources, connections

### Backup System
- Auto-backups every 10 conversations
- Session backups on clean exit
- Emergency backups on crash
- Includes integrity hash verification

### Survival Thread
- Runs in background
- Monitors health every 5 minutes
- Creates periodic backups
- Self-healing capabilities
